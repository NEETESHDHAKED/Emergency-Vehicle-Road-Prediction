# 🚑 Emergency Vehicle Road Prediction

An End-to-End Machine Learning project designed to predict **road suitability and routing priority for emergency vehicles** using traffic and road-related features.

The project combines **Data Science, Machine Learning, and Flask Web Development** to provide predictions through an interactive web dashboard.

---

## 🎯 Project Objective

Emergency vehicles such as ambulances and fire trucks need efficient and suitable routes to reach their destinations quickly.

This project analyzes different road and traffic conditions to predict the **suitability and priority of roads for emergency vehicle movement**.

The complete workflow includes:

**Data Processing → EDA → Feature Engineering → Machine Learning → Prediction → Flask Deployment**

🚀 Installation & Setup
1. Clone the Repository
git clone https://github.com/NEETESHDHAKED/Emergency-Vehicle-Road-Prediction.git
2. Navigate to the Project
cd Emergency-Vehicle-Road-Prediction
3. Create a Virtual Environment
python -m venv venv
4. Activate the Environment
Windows
venv\Scripts\activate
Linux / macOS
source venv/bin/activate
5. Install Dependencies
pip install -r requirements.txt
6. Run the Application
python app.py

Then open the local Flask URL shown in your terminal.
